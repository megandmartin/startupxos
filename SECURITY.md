# Security

Please report security problems privately, not in a public issue: open the **Security** tab of this repository and choose **Report a vulnerability**, or use [this link](https://github.com/megandmartin/startupxos/security/advisories/new).

Include the app version, your platform (Mac, Windows or web preview) and the steps to reproduce. Please leave out real passwords, recovery keys and company data.

To check that an installer is genuine, compare its SHA-256 with the value on its [release page](https://github.com/megandmartin/startupxos/releases) or in [SHA256SUMS.txt](https://www.startupxos.com/releases/SHA256SUMS.txt).
