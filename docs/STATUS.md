## In the desktop preview

- A local encrypted company workspace, with a vault password and optional recovery key.
- Guided company setup and selected import of Markdown/text notes.
- A company brain with note relationships and access to original wording.
- Saved founder decisions, their reasons and next steps.
- Configuration for supported AI tools, including Claude Code and Codex. Tool registration and a successful read are separate checks.

## Boundaries worth knowing

- Connecting an external provider can send the context you permit to that provider. Provider accounts and usage are separate from the app.
- An imported folder is not automatically kept in sync. Re-importing and source-folder access are explicit steps.
- The website's agent scenes illustrate planned workflows using fictional data. They are not evidence that customer follow-ups or investor updates run unattended in this preview.
- Desktop and cloud workspaces are separate. Automatic cross-device sync and self-serve team sharing are not included in this preview.
- Windows hardware acceptance, upgrade/recovery on a particular device and live provider behavior need their own observations. A green source check does not replace those checks.

## A useful first test

Start with a fictional company and two small notes. Import both, check the originals, save a private decision, then quit and reopen. Confirm that the same company, notes and decision return. Imported notes start private, so a connected AI should withhold their contents until you explicitly share only the notes you intend it to use. Test factual retrieval only after that deliberate sharing step; if the app does not offer a clear sharing action, skip retrieval and check that unshared content stays unavailable.

When reporting a problem, include version, build, distribution channel, operating system and the steps taken. Keep all real company data and credentials out of public issues. [Private security reporting](../SECURITY.md) is available for security concerns.
