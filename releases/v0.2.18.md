# startupxOS 0.2.18

**Mac public preview · released on the website 20 November 2026**

A simpler first run, starting with the notes and AI tools you already use.

- **Guided setup.** Name your company and yourself, then choose an AI connection and a work source. Later steps can be skipped and revisited.
- **Bring your second brain.** Preview a folder of `.md`, `.markdown` or `.txt` files, choose what to import, and save selected files in your private workspace. Original files are unchanged.
- **Keep the source nearby.** Browse imported notes and their relationships, and open their original wording.
- **Connect Claude Code or Codex.** The TestFlight build offers an app-generated Terminal line for setup. Restart the tool if it was already open and confirm a real connection before treating setup as complete.
- **Signed Mac download.** The website offers a Developer ID signed and notarized disk image for Apple Silicon Macs running macOS 15 or later.

## Preview notes

- The website download and invitation-only TestFlight builds are different distributions. Report which one you used and the build number shown on your device.
- A local import is a selected copy, not background folder sync. Pick the source folder again to bring in changes.
- TestFlight folder access can require selecting the folder again after restarting. A follow-up for resuming an unfinished import was uploaded for internal testing on 23 November; tester availability and the native restart check were not yet confirmed when this record was prepared.
- An initial recap can still ask for a source after an import. Check the imported notes in Brain separately from the recap wording.
- Optional external AI and connectors can receive authorized context. Real provider access, recovery and upgrades require checks on the build and device you use.
